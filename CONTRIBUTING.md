# Участие в разработке

## Раскладка

```
frontend/            клиент (React + TypeScript + Vite)
programs/pool_tmp/   Anchor-программа
scripts/             вспомогательные скрипты
tests/               тесты программы
```

## Правило, которое не нарушаем

Весь доступ клиента к сети идёт только через `frontend/src/lib/ortaq`.
Ни один компонент не импортирует `@coral-xyz/anchor` или `@solana/web3.js`
напрямую — компоненты знают только про интерфейс `OrtaqClient`.

Смена реализации (`mock.ts` -> `chain.ts`) должна быть работой в одном файле,
а не по всему проекту.

## Деньги

Все суммы — целые числа в базовых единицах токена, 6 знаков.
`10.50` в интерфейсе = `10500000` в программе.

Float в денежной арифметике не используется: ввод разбирается построчно,
вывод собирается из целых. Причина простая — `0.1 + 0.2` в double не даёт
`0.3`, и расхождение между экраном и цепочкой ловится потом очень дорого.

## Перед коммитом

```
cd frontend && npm run typecheck && npm run build
anchor build && anchor test
```

## Секреты

`.env.local` и приватные ключи не коммитятся. RPC-ключи держим в переменных
окружения, а не в `Anchor.toml`: репозиторий публичный.
