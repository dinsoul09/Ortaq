# Ortaq

Общая касса без казначея. Деньги на общий сбор держит программа на Solana:
до достижения цели их не трогает никто, а если собрать не удалось — взносы
возвращаются участникам.

Счёта, принадлежащего группе, в банковской модели не существует — счёт всегда
чей-то. Здесь сбор не принадлежит никому из участников, и правило исполняет
программа, а не человек.

## Как это работает

1. Организатор создаёт сбор: получатель, цель, срок. Получатель фиксируется
   при создании и потом не меняется — в том числе самим организатором.
2. Участники вносят взносы. Деньги лежат в vault сбора (PDA), а не на кошельке
   организатора.
3. Цель достигнута — `release` переводит всё получателю. Вызвать может кто
   угодно: программа проверяет владельца и mint токен-аккаунта, так что деньги
   всё равно уйдут только получателю.
4. Срок вышел, цель не собрана — участник забирает свой взнос обратно
   через `refund`.

## Структура

```
app/                 клиент: React + TypeScript + Vite + Tailwind
programs/pool_tmp/   Anchor-программа
target/idl/          IDL программы
tests/               тесты программы
```

Весь доступ клиента к сети идёт через `app/src/lib/ortaq` — компоненты знают
только про интерфейс `OrtaqClient`. Реализаций две: `mock.ts` (в памяти,
для разработки экранов) и `chain.ts` (реальная). Переключается переменной
`VITE_USE_MOCK`.

## Запуск клиента

```
cd app
npm install
npm run dev        # --host, чтобы открыть с телефона в локальной сети
```

Переменные окружения — `app/.env.local`, образец в `app/.env.example`.

## Состояние

Прототип. Только devnet и тестовый SPL-токен, мейннета нет. Суммы считаются
целыми числами в базовых единицах токена (6 знаков): `10.50` в интерфейсе —
это `10500000` в программе.
